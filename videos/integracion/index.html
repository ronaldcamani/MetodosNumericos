ESCENA 2 / 5 · TRAPECIO O(h²)

Regla del Trapecio compuesto (orden O(h²))

Conecta puntos consecutivos con cuerdas rectas aplicando pesos (1, 2, 2, 2, 1). Como t² + 1 es convexa, sus segmentos rectos sobrestiman ligeramente el área exacta.

T₄ = (h/2)·[1 + 2(1.25 + 2 + 3.25) + 5] = 4.7500
ESCENA 3 / 5 · SIMPSON 1/3 O(h⁴)

Regla de Simpson 1/3 compuesto (orden O(h⁴))

Requiere n par y reemplaza pares de subintervalos por arcos parabólicos con pesos (1, 4, 2, 4, 1). Para cualquier cúbica, su error de truncamiento es idénticamente cero.

S₄ = (h/3)·[1 + 4(1.25 + 3.25) + 2(2) + 5] = 4.6667
